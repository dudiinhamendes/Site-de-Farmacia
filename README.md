# 🏥 Site de Farmácia

> Projeto Full Stack desenvolvido no Curso Técnico em Informática.

O projeto consiste no desenvolvimento de um sistema web completo para uma farmácia, utilizando a biblioteca **React** no Front-end para a criação de uma interface de usuário (UI) dinâmica e interativa, integrada a um ecossistema Back-end. O objetivo principal foi aplicar conceitos de desenvolvimento web, organização de conteúdo e integração de ponta a ponta.

## 🚀 Funcionalidades
- Carrinho de compras para medicamentos e produtos.
- Busca e filtragem de produtos por categoria.
- Sistema de login e cadastro de usuários.

## 🛠️ Tecnologias Utilizadas

### Front-end
- **React**
- **JavaScript** 
- **CSS**

### Back-end
- **Python** 
- **UV** 

### Banco de Dados 
- **XAMPP**
- **MySQL**
